# UML Viewer

UML Viewer helps readers explore a codebase's structure and behavior.

## Language

**Selection context**:
The currently selected structure element or behavior step and the information shown about it in the Context panel.

**Architecture context**:
The real diagram or a proposed structure currently being discussed.

**Workflow**:
A named, code-grounded account of how the system carries out a task. Its steps may cross process or file boundaries and need not describe an observed execution.

**Workflow stage**:
A broad part of a workflow that can contain named function steps.

**Curated explanation**:
Authored prose about a selected structure element or workflow step, kept distinct from facts extracted from code.
